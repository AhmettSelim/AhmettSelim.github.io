# English Arena website

Official landing page for **English Arena: World Battle**, published with GitHub Pages at [ahmettselim.github.io](https://ahmettselim.github.io/).

## Local preview

Serve the repository root with any static file server, then open `index.html` through that server. For example:

```powershell
python -m http.server 4173
```

The public `app-ads.txt` file must remain at the domain root.
